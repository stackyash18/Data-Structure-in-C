# Data Structure in C

This repository contains my practice programs for Data Structures implemented in C language. These programs were created while preparing for exams and strengthening my understanding of fundamental data structure concepts.

## Topics Covered

### Linked List
- Creating a Linked List
- Traversing a Linked List
- Traversing a Circular Linked List
- Traversing a Header Linked List
- Insert at Beginning
- Insert After a Node
- Delete at Beginning
- Search Key (Iterative)
- Search Key (Recursive)
- Reverse Linked List (Iterative)
- Reverse Linked List (Recursive)

### Queue
- Queue Using Array
- Queue Using Linked List
- Enqueue Operation
- Dequeue Operation
- Initialize Queue
- Check if Queue is Empty
- Circular Queue

### Stack
- Stack Implementation
- Push Operation
- Pop Operation

### Recursion
- Basic Recursion Programs
